## 简介

MihonSY 是 [TachiyomiSY](https://github.com/jobobby04/TachiyomiSY) 的一个分支，在保留上游全部特性的基础上，强化了**图像增强**、**条漫阅读体验**与**多设备同步**。

- 端侧图像增强：经典插值 + AI 超分（GPU / NPU）
- 条漫阅读体验优化
- 基于 WebDAV 的多设备同步：书架、进度、历史、书签与设置


---

## ✨ 核心功能

### 1. 图像增强

- **AI 超分（GPU）**：ncnn + Vulkan，内置 AnimeVideoMiniV18 / OmniMiniV2（默认）/ OmniTurboV15 三个模型，固定 2x。
- **AI 超分（NPU）**：Qualcomm QNN / HTP 硬件加速。
- **Lanczos3 / Catmull-Rom**：经典插值，支持 **1.5x / 2x / 2.5x / 3x** 四档倍率（native 分离卷积实现）。
- **降噪**：与增强解耦的独立开关（默认关），只平滑亮度、保持色相。
- **增强状态角标**：独立开关（默认关），在图片左下角显示实际生效的引擎、耗时与输出分辨率，未增强时显示「跳过」。
- NPU 模型以**独立模型包 APK** 形式分发。


### 2. 条漫阅读增强

- **点击滚动距离**：半屏 / 3/4 屏 / 全屏，三档可选（按阅读器实际可视高度计算，平板也能滚满一屏）。
- **滚动动画**：时长 0–1000ms 可调（0 = 瞬时跳页）。
- **瞬时触发**：v1.1.0 起点击改为瞬时触发，更跟手流畅。
- **原始分辨率**：条漫按原始像素 1:1 显示，不缩放。
- **预载设置**：v1.1.0 新增，页漫与条漫均可设置预载页面 / 屏幕数量；接近章末时还会提前预载下一章首屏，跨章更顺。


### 3. 自动条漫判定增强

- 保留原版标签判定（webtoon / long strip 等）。
- 新增**按图片比例判定**：首页为长条图（高/宽 > 2.5）自动切条漫。
- 命中后**按书粘住**：同一部作品后续章节直接按条漫打开；若该作品是图文混排（复审不通过）则退回标签与默认判定。

### 4. Komga 进度逐本同步

- 改为对实际读到的单话逐本 `PATCH /api/v1/books/{id}/read-progress`，**其他章节不受影响**，进度精确到话。

### 5. 多设备同步（WebDAV）

- **三条实时小通道**：阅读进度、阅读历史、按页书签各走独立远端小文件，**实时同步**，不等全量同步的周期。
- **删除也会同步**：删除一律留下墓碑再传播；账本记录本机上次同步拥有哪些数据，因此在一台设备删掉的作品、书签不会被另一台拉回来。
- **逐项可选**：书架、分类、章节、阅读状态、历史、书签、自定义信息、保存的搜索、应用 / 来源 / 扩展商店设置等 13 项可分别勾选；书架类多端取并集，设置类按本机选择各自保留。
- **触发条件自己定**：打开章节、退出章节、打开书架各一个开关；「启动应用」「回到应用」可选「历史与书签」或「全量同步」；勾上的全量同步每次都会执行，不受同步频率节流。
- **通知干净**：同步与自动备份默认不产生任何通知（也不进前台服务），仅在出错时通知。


### 6. 书签与阅读历史

- **底部「书签」页签**：跨作品汇总所有按页书签，点击直达该作品该章该页；不需要时可在 设置 → 外观 隐藏。
- **书签可备份、可同步**：备份 / 恢复新增「按页书签」分段；书签支持跨端同步，删除同样会同步。
- **阅读器内书签列表**：长按阅读器书签按钮可查看当前章节的书签。
- **历史显示页数进度**：历史条目显示「已读 / 总页数 · 百分比」。
- **继续阅读按历史续读**：从阅读历史取下一章，而不是只看章节列表顺序。

### 7. 深度裁剪边缘

- 增强裁边算法，选择后**裁边可以穿过水印与页码**，不再被水印挡住。



## ⚠️ 注意事项

- 内置更新检查会访问 `ruzhe85/MihonSY` 的 Releases（最多每 3 天一次，自动忽略 pre-release）。
- 多设备同步：**只有 WebDAV** 带进度 / 历史 / 书签三条实时小通道；Google Drive 与 SyncYomi 仅做全量同步。
- 与官方 TachiyomiSY 包名不同，可共存，但**备份/恢复时注意区分数据**。
- 仅个人学习使用，请遵守所读漫画的版权。
